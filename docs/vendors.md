## Decisions worth remembering
- **2026-08**: Dropped IONOS Deploy Now / web hosting. Its GitHub integration was gated behind a hosting tier despite an existing paid plan, and the account kept redirecting to a purchase flow instead of exposing the feature. Kept the domain registration at IONOS (registrar and hosting are separate products — no need to move both just because one had a bad UX).
- **Registrar note**: IONOS's ~$20/yr is above wholesale (~$9-10) but not unusual for a non-discount registrar. Not worth transferring for the ~$10/yr difference given transfer friction (60-day lock, EPP code, similar one-time cost). Revisit at renewal, not mid-launch.
